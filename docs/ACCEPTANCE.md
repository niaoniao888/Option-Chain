## 前端读取失败与超时保护（2026-09-26）

- 前端轮询按自身 `AbortSignal` 状态和 `reason` 区分超时、页面隐藏及停止，不再依赖拒绝值必须是带 `AbortError` 名称的 `Error`。4500ms 请求超时、5000ms 常规轮询及原有重试边界保持不变。
- 字符串、`null` 或普通对象等拒绝值统一生成安全错误文案，不再向页面显示 `undefined`；页面隐藏和停止造成的主动取消不显示读取失败。
- HTTP 成功后读取响应正文期间若被取消，该请求按失败处理，不会把伪空 payload 提交并覆盖现有快照。浏览器测试覆盖失败时旧表格保留以及后续成功响应恢复。
